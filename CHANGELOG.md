# Changelog

## Unreleased

### Changed
- Renamed the app from Focus Block to Tickover and added a new icon. The desktop app moves an existing Focus Block data folder to the new location on first launch.
- The daily study limit is now optional and off by default. It counts time already studied plus time still planned, so finishing a block no longer frees time, and the separate protected buffer was removed. The limit field saves as you type.
- Desktop apps show a menu-bar (Mac) or system-tray (Windows) icon while running, with Open and Quit, and a Settings option to hide it. Windows builds without a console no longer fail at start-up because of missing output streams.
- Added color themes (Rose, Ember, Forest, Ocean, Slate) and a Custom theme with your own colors. Fonts remain a separate choice.
- The copied agent instructions now explain that every task needs an `external_id`.
- Documented that the bundled sounds are generated by code, and added `tools/generate_sounds.py`.

## 1.3.0 — Release candidate

### Scheduling and planning
- Added task priorities, optional deadlines, and protected/locked tasks.
- Added daily study capacity and protected buffer settings.
- Added capacity-aware rollover with automatic, approval-first, and manual modes.
- Added rollover previews, revision checks, activity history, and guarded undo.
- Added agent plan previews with additions, updates, removals, capacity impact, and protected-task conflicts.
- Preserved task IDs, completion state, notes, sub-items, and study progress when an agent refreshes a plan using stable `external_id` values.
- Added optimistic revision checks to reduce lost updates from concurrent agents and users.

### Timer and reporting
- Added backend timer auto-advance while the local application server remains running.
- Added rollover and task-completion indicators to productivity reporting.
- Added protection against deleting a task while its timer session is active.

### Reliability and distribution
- Removed seeded personal study-plan data from fresh databases.
- Fixed timezone/configuration load ordering and desktop timezone handling.
- Fixed database backup path handling and added validated backup restore with a pre-restore safety copy.
- Added an installable PWA shell; API responses are not cached.
- Added GitHub Actions workflows for tests and native macOS/Windows release builds.
- Added publishing, security, and asset-license review documentation.

### Notes
- This is a single-user, local-first release. It is not a shared multi-user hosted service.
- The supplied audio files still need provenance/license confirmation before public redistribution.
- Desktop builds from GitHub Actions are unsigned and unnotarized.
